# Security Policy

Neobrutalism is a pure CSS theme. It runs no scripts and makes no network requests, the fonts are embedded in `theme.css`. The helper scripts in `scripts/` are only used during development and are not part of the installed theme. The risk of security issues is therefore very low.

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

If you still find something security related, please do not open a public issue. Instead, report it privately through [GitHub's security advisories](https://github.com/LennZone/Neobrutalism/security/advisories/new). You will get an answer as soon as possible.
