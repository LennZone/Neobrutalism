# Accessibility

Neobrutalism uses bold outlines and clear boxes, which already helps to tell areas and controls apart. This page lists what the theme does on top of that.

## What the theme does

- **Clear outlines**: panels, buttons and inputs have visible borders, not only a change in background color.
- **Focus** stays visible for keyboard navigation: focused buttons get an outline in the border color.
- **Reduced motion**: the hover and click movement is turned off when your system asks for reduced motion, and can also be turned off in the Style Settings.

## Adjusting the theme

With the [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin you can change the border width, every color (separately for light and dark mode), the fonts, and turn off the dotted background.

## Feedback

If something is hard to read or use, for example with a screen reader, high zoom or a specific color setting, please [open an issue](https://github.com/LennZone/Neobrutalism/issues/new/choose). Accessibility problems are treated as bugs.
